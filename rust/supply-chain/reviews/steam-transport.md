# Steam transport and identifier hardening

Source came from exact crates.io archives whose SHA-256 values match the locked graph. Runtime sources and original metadata were extracted from those archives before patching. Each vendor directory records its original version, provenance and changes. These local patches are intentionally not represented as audits of the unmodified published releases.

| Package | Concrete changes | Local validation |
|---|---|---|
| [steam-vent 0.5.0](../../vendor/steam-vent/CAMA_PATCH.md) | Check frame/header lengths before allocation or splitting; cap frames at 16 MiB, headers at 64 KiB and inflated multi bodies at 32 MiB; verify declared gzip size/CRC and child framing. Validate auth/heartbeat intervals. Remove payload/key tracing and TLS key logs; redact token/session diagnostics. Cancel filter/heartbeat workers, unregister failed/timed-out/cancelled jobs, and prevent one full subscriber queue blocking all replies. Enforce GC app ID and inner/outer kind agreement. Use explicit ring TLS and the existing reqwest 0.12 graph. | 20 library tests passed, including malformed input, resource cleanup, stalled writes, routing and credential sentinels. |
| [steam-vent-crypto 0.2.1](../../vendor/steam-vent-crypto/CAMA_PATCH.md) | Reject short/unaligned ciphertext before splitting; verify Steam's truncated HMAC through the constant-time primitive API. | 7 library tests passed, including each corrupted tag byte and empty/multiblock round trips. |
| [steamid-ng 3.0.0](../../vendor/steamid-ng/CAMA_PATCH.md) | Reject Steam2 account arithmetic overflow and confine public Instance values to their 20-bit field. | 2 new library regressions passed. |
| [tungstenite 0.29.0](../../vendor/tungstenite/CAMA-PATCH.md) | Redact request/frame/payload/close-reason logs; align the two fixed-size random-byte uses with rand 0.10.2, removing the redundant rand/getrandom branch. | 44 library tests passed. Logging regression rejects literal and hex-encoded secret sentinels. |
| [const-oid 0.9.6](../../vendor/const-oid/CAMA-PATCH.md) | Replace recursive unchecked decimal parsing; reject missing arcs and binary accumulator overflow/nonminimal encodings. Correct base128 arc-128 encoding and two-byte OID round trips. | 12 library tests passed, including 100,000 leading-zero digits and numeric boundary cases. |

Independent comparison of tungstenite and const-oid changes against their original archives found the additional OID decoder/encoder bugs above and a gap in the logging test's hex detection. Those findings were fixed before freezing reviewed source. Unsafe tungstenite UTF-8 access follows validated constructors; its byte-to-word masking uses disjoint aligned slices. The review covers the supported 64-bit Linux deployment, not a new certification of 32-bit length conversions.

Steam's production authentication entrypoint has a 90-second outer deadline, including server discovery. Interactive bootstrap can wait for two-factor input; reqwest's default client does not supply a total request timeout. Cama uses WSS and a custom credential store with restrictive atomic writes; the upstream default store's umask-dependent behavior is not used. Documented caller contracts, such as the legacy 16-byte encryption IV buffer and explicitly unauthenticated helper, remain caller obligations. No live Steam connection was needed for these regressions.

Steam and its crypto crate declare MIT in their original manifests, but the published archives omit a standalone license file. The pinned Steam repository root also contains none. Original metadata is retained rather than fabricating a copyright notice. Other vendor directories preserve the licenses actually shipped upstream.
